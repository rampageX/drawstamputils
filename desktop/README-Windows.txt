DrawStampUtils Windows x64 便携版
===============================

1. 将 ZIP 完整解压到一个可写的文件夹（如 D:\Tools\DrawStampUtils）。
2. 双击 DrawStampUtils.exe 启动，不需要 Node.js 或浏览器。
3. 图片及模板导入/导出均在本地完成。可断网使用。
4. 软件设置保存在 EXE 同级的 Data 文件夹中；迁移时连同 Data 一起复制。
5. 程序未进行代码签名，Windows 首次启动可能显示 SmartScreen 提示。
6. 不要只把 EXE 单独拷走：需要保留整个解压目录。

这是基于 https://github.com/xxss0903/drawstamputils 的独立 Windows 桌面封装。
